# CMPB review: post-lock analysis and larger figure typography

This is an additive review branch. The original trained models, training code,
normalization, data splits, graph budgets and original protocol lock are unchanged.
Do not rerun notebooks 02, 06, 07, 09, label-permutation training in 12, or 12c
merely to regenerate figures. Do not refreeze the original protocol to conceal
post-lock edits.

## Figure-only patch

From the repository root:

```bash
python tools/apply_cmpb_review.py
python tools/apply_cmpb_review.py --apply
```

The first command checks the expected source fragments without writing. The
second saves original bytes in `_backup_before_cmpb_review/`, updates the main
figure module and notebooks 10/13, and writes `cmpb_patch_audit.json`.
The downloadable code bundle supplied with this review already has this patch
applied; it does not require another application.

Run notebook 10 for the main quantitative figures and notebook 13 for S2/S3.
Outputs go to NEW directories ending in `_large_fonts`. Typography is controlled
by `configs/publication_style.json`: titles 20 pt, panel titles 16 pt, labels
14 pt, ticks 13 pt, legends/annotations 12 pt, gene labels 12.5 pt. SVG text
remains editable; PDF/SVG/600-dpi PNG exports are retained. Font sizes are applied
idempotently, including previously hard-coded small annotations. Inspect the
rendered figures at their final manuscript width.

The signature-coverage/rewiring panels describe the Exact-K consensus networks,
not the strict 5/5 cores. Raw signature fractions are called coverage, not
size-adjusted specificity. In the supplied paper this separates 529 consensus
edges from the 299-edge Basal-like strict core. Figure 1 is a separately authored
workflow and is not regenerated by notebook 10.

## Additional analysis, not retraining

```bash
python tools/run_cmpb_review.py
```

This reads the cached candidate effects from 08b and the existing factorial
InterGATE/q panels from 12. It never loads model checkpoints or selects new
panels. It exports directed-row and unique-pair concordance, reciprocity,
within-scope BH adjustment over unique strict-core pairs, descriptive matched-
selector comparisons and null-normalized signature recovery. Missing inputs
are reported, not synthesized; no earlier notebook runs automatically.

An optional patient-paired bootstrap is available in
`intergate.review_external_bootstrap.run_patient_bootstrap`. Supply the same
prepared post-lock runtime as 08b. It requires the original sample counts and
reproduces the frozen effects before resampling patients within cohort and
case/rest stratum. Every resample is shared by both methods; development effects,
panels, preprocessing and cohort weights stay fixed. The centered bootstrap
p-value is approximate, not an exact permutation test. Development/selection
uncertainty is not estimated. This is explicitly an additional post-hoc analysis.

The original directed matched null must not be reused as a unique-pair matched
null. Correlation sign concordance does not validate regulatory orientation.
No new empirical result or improvement over q is claimed until these analyses
have actually run on the complete stored results.
