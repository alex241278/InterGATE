# Retrained graph-only predictive comparator

The five original Phase 1 states and their corresponding predictive graph topologies are the starting inputs. The graph comparator excludes the direct gene-expression tabular trunk. After five warm-up epochs with the graph-derived covariates zeroed, the four graph experts can use the original 7,677 regulator summaries. The code freezes structural parameters, bypasses structural gates and uses per-class fixed graphs. Checkpoint choice uses the 743-case development validation partition. Updated parameters, including message-passing and prediction layers, are fitted on the original 2,970-case training partition. The seed-specific checkpoints from the original fused Phase 2 predictor do not initialise this branch refit.

Training uses AdamW with learning rate 0.0004 and weight decay 0.0001, batches of eight with 20-batch gradient accumulation, and class-weighted cross-entropy. Mixup with beta parameter 0.15 and probability 0.30 and the expert loss with coefficient 0.2 apply during the second stage. This stage lasts up to 80 epochs and stops after 20 epochs without validation macro-F1 improving by more than 0.0001. Fit histories and selected checkpoints are written per seed. The code reproduces the training and validation index hashes from the archived paired benchmark before each fit or evaluation launched with the revised driver. An external evaluation requires a completed development fit. No external data are read in the fit stage.

Seeds 1234, 7, 99 and 31337 used CPU. After the initial seed 1234 pilot ended during fitting, the analysis restarted from its archived Phase 1 initialisation, with four CPU threads and the same seeded data loaders. The six-epoch pilot is preserved as an intermediate diagnostic. The seed 2025 worker used the RTX 3090. All analysed fits use the original Torch311 environment, Python 3.11.9 and PyTorch 2.7.1+cu118. Isolated warm-up diagnostics run with another version of PyTorch are excluded. `finish_graph.py` collects the five independent fits and evaluates the five frozen models in the same order as the tabular and fusion comparators. It verifies the patient indices, labels, cohorts, and probabilities before writing `graph_branch_audit.csv`. To reproduce in a fresh output directory, use `train_branches.py graph fit --threads 4` followed by `train_branches.py graph evaluate --threads 4`, then run `summarize.py` with both branch fits and evaluation tables present. To exactly reproduce the reported backends, run seed 2025 on CUDA with two host threads, seed 1234 on CPU with four threads, and each of seeds 7, 99 and 31337 on CPU with three threads. Local outputs are not part of the original study.

The reported bootstrap resamples the 1,143 external patients within their observed cohort and subtype. Each draw uses the same patients for all three classifiers. Probabilities are first averaged over the five fitted seeds. The percentile intervals from 2,000 replicates are conditional on the fitted ensembles and the observed cohort and subtype composition. `paired_external.csv` contains absolute macro-F1, Basal-like F1 and paired fusion-minus-comparator differences.
